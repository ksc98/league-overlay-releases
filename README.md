# League Overlay releases

Installers for League Overlay, a Windows companion app for League of Legends.

Download the newest `league-overlay_<version>_x64-setup.exe` from [Releases](../../releases/latest) and run it. It installs for your Windows account (no admin). Installed copies update themselves from this page.

Windows SmartScreen may warn because the installer isn't signed: **More info → Run anyway**.
